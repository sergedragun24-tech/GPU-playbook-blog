Чек-лист MLOps (технический проход)
Один узел или кластер: рекомендация соответствует масштабу задачи (кластер не подменяется «выделенным сервером»).
Сценарий доказательства совпадает со сценарием статьи: замер межсерверного обмена не подтверждает тезис про одиночный сервер, и наоборот.
Выделенный сервер — тоже облачная услуга. Не противопоставлять «облако» и «выделенный сервер»; противопоставлять Cloud GPU (ВМ) и выделенный сервер.
bare-metal и выделенный сервер не синонимы: bare-metal — поставка без виртуализации, выделенный сервер — название услуги, он бывает и с гипервизором.
Связь GPU внутри сервера: NVLink есть не во всех серверах (у L40S и RTX PRO 6000 его нет), иначе PCIe.
Сеть между узлами: InfiniBand/RoCE, RDMA. Для кластера из ВМ — есть ли RDMA между ВМ.
Влезает ли модель в видеопамять одного GPU / одного сервера.
Точность вычислений: FP64 vs FP32/смешанная точность; назначение ускорителей.
Инференс: задержка vs пропускная способность; холодный старт при автомасштабировании.
Разделение GPU: MIG (аппаратная изоляция) vs vGPU с разделением по времени — не описывать одной фразой.
«Шумные соседи»: при ВМ с целым GPU общими остаются CPU, сеть, хранилище.
Распределенное обучение: обмен градиентами, хранилище для данных и контрольных точек, планировщик (Slurm — стандарт HPC и обучения LLM; Kubernetes — оркестратор контейнеров).
Топология PCIe: отметки PIX и PXB достижимы только на платформах с коммутаторами PCIe. На машинах с двумя-четырьмя картами норма — PHB или NODE.
ACS: внутри ВМ не отключается. Без ACS ломается проброс отдельного устройства, а не виртуальная машина целиком.
Автоматическая балансировка NUMA в ядре отменяет привязку через numactl. Отключается на ходу через sysctl, перезагрузка нужна только для записи в параметры загрузки.
Универсальные утверждения без оговорок; завышенные обещания без механизма.
Связь утверждений с механизмом (например, Tier III — это доступность, а не задержки).
Последовательность шагов в рекомендациях: пилот → проверка масштабирования → полный кластер.
Выполнимость совета: рекомендация клиенту проверяется на реализуемость в его условиях.

Литературный проход (отдельно от технического)
Повторы ищет скрипт: частотность слов по абзацам и в соседних предложениях. Затем проверка вручную.
Хвосты фраз, избыточные блоки, дублирование между разделами, таблицей и FAQ.
Канцелярит и усилители («напрямую влияет», «обеспечивает», «как…, так и…»), маркетинговые формулы.
Грамматика: деепричастия без субъекта, согласование вопроса и ответа в FAQ, дефисы в составных словах.
Однотипные конструкции подряд (двоеточия, «то есть», «например», «— это» в продуктовом блоке).
Сверка с `ITGLOBAL_Glossary.md`: русификация терминов, термины без перевода, кальки, запрещенные обороты.
Прямые указания пользователя: без тире-вставок, без «не X, а Y», без отсылок к другим разделам. Эти три запрета стоят выше регистра по решению пользователя. Сам регистр оборот «не X, а Y» разрешает в лиде, определении и выводе раздела с пределом три-четыре на статью, поэтому запрет и регистр здесь расходятся. Действует запрет.
Заголовок называет предмет, а не отношение между безымянными вещами. Назывной заголовок допустим, если называет вещь.
Раздел не заканчивается технической припиской. Последний абзац раздела несет вывод, а не примечание к предыдущему абзацу.
Размытые отсылки считаются сплошняком по всему тексту, а не ловятся по одной. Каждая отсылка заменяется названием предмета.
Глагол называет действие точно. Неточный глагол в описании механизма — такой же дефект, как неверное число.
Предложения длиннее 28 слов пересобираются. Проверяется скриптом после сборки, в том числе на абзацах, которые появились в ходе правки.
Ударная формула не повторяется. Если формулировка снята в лиде, она снимается и в «Итогах», и в заголовках разделов. Одна и та же ударная фраза в двух местах статьи считается повтором.
Третий синоним убирается. На один предмет держатся два сквозных термина, не больше. Третье название снимается по всей статье.
Ось сравнения без отдельного раздела убирается целиком. Вместе с ней уходят строки таблицы, вопросы FAQ и упоминания в других разделах. Проверка осиротевших ссылок выполняется в том же ходе.

Способ счета объема
Задан Сергеем 15.10.2026 при прогоне статьи про расчет GPU под инференс. Это единственное место хранения способа счета. Сам коридор объема задан в инструкциях проекта, здесь не повторяется.
Считаются знаки без пробелов по очищенному тексту. В счет идет то, что читатель читает как текст.
Перед подсчетом из текста убираются:
решетки заголовков;
звездочки и подчеркивания выделения;
обратные кавычки;
маркеры списков в начале строки;
вертикальные черты и разделительные строки таблиц;
адреса внутри `[текст](адрес)`, сам текст сохраняется;
голые адреса http и https.
Затем убираются все пробелы, переводы строк и табуляции, и считается длина остатка.
Голые адреса не считаются по решению Сергея: адрес источника текстом не является, а число источников у статей разное, и коридор съедался бы ссылками.
Коридор 8000–10 000 и потолок 12 000 относятся к числу, полученному этим способом.
Скрипт, воспроизводящий счет:
```python
import re, sys

def ochistit(t):
    t = re.sub(r'```.*?```', '', t, flags=re.S)                      # блоки кода
    t = re.sub(r'\[([^\]]+)\]\([^)]*\)', r'\1', t)                   # [текст](адрес) -> текст
    t = re.sub(r'https?://\S+', '', t)                               # голые адреса
    t = re.sub(r'^\s{0,3}#{1,6}\s*', '', t, flags=re.M)              # решетки заголовков
    t = re.sub(r'^\s*\|?[\s:\-|]+\|[\s:\-|]*$', '', t, flags=re.M)   # разделительные строки таблиц
    t = t.replace('|', ' ')                                          # вертикальные черты
    t = t.replace('`', '')                                           # обратные кавычки
    t = re.sub(r'[*_]+', '', t)                                      # звездочки и подчеркивания
    t = re.sub(r'^\s*[-+*]\s+', '', t, flags=re.M)                   # маркеры списков
    return t

for p in sys.argv[1:]:
    print(len(re.sub(r'\s', '', ochistit(open(p).read()))), p)
```
Эталонные числа для проверки скрипта, история правки и открытый вопрос про номера нумерованных списков остаются в журнале `claude/GPU_Inference_Sizing_decisions.md`, раздел «Способ счета объема». Сюда перенесен только способ счета.
